# Bundled fonts

These are latin variable subsets, served from this directory by webpack so the
site makes no third-party font requests.

| File | Family | Style | Weights | Upstream |
| --- | --- | --- | --- | --- |
| `inter.woff2` | Inter | normal | 400–700 | https://github.com/rsms/inter |
| `jetbrains-mono.woff2` | JetBrains Mono | normal | 400–700 | https://github.com/JetBrains/JetBrainsMono |
| `newsreader-italic.woff2` | Newsreader | italic | 400–600 | https://github.com/productiontype/Newsreader |

All three families are licensed under the SIL Open Font License, Version 1.1.
