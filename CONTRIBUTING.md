# Contributing Guide

Thanks for wanting to contribute! Here's how you can help.

## How to Add Questions

1. Fork this repository
2. Find the right topic folder (or create one)
3. Add your Q&A following the format below
4. Submit a Pull Request

## Q&A Format

```markdown
## Q: Your question here?

**Summary:**
Clear, concise explanation (2-4 sentences).

**Key points:**
- Point 1
- Point 2
- Point 3

**Learn more:**
- [Doc Title](https://link-to-official-docs)
```

## Guidelines

- Keep summaries short and focused on interview recall
- Always link to official documentation, not blog posts
- One topic per file (e.g., `file-system.md`, `networking.md`)
- Use diagrams/images when they help explain concepts (put them in `images/`)
- Check for duplicates before adding a new question
- Keep language simple and beginner-friendly

## Adding a New Topic

1. Create a new folder with the topic name (lowercase, hyphens)
2. Add your first Q&A file
3. Update the README.md table of contents

## Reporting Issues

If you find incorrect information or broken links, please open an issue.
